# Labs

## 워크샵 한 판은 명령 두 줄 사이에 있습니다

```bash
uv run ffsft infra up   --prefix <본인> --location <region>   # Lab 0 — 열기
...
uv run ffsft infra down --prefix <본인> --yes                 # Lab 7 §7 — 닫기
```

- **이름은 하나만 정합니다** — 여러분의 prefix. 리소스 그룹·워크스페이스·스토리지·ACR·
  KeyVault 이름이 전부 거기서 나옵니다.
- **리소스 그룹은 하나입니다.** Lab 이 그룹을 더 만드는 일은 없습니다. 그룹이 청구 경계이자
  삭제 단위이기 때문입니다 — 하나면 `infra down` 한 줄로 워크샵 전체가 사라집니다.
- **리전도 하나입니다.** [Lab 0 §3](lab0.md) 에서 학습 SKU 와 서빙 SKU 를 **둘 다** 파는
  리전으로 고릅니다. 중간에 갈아타는 단계는 없습니다.
- **셸도 하나입니다.** `source ~/.ffsft-env` 하나로 Lab 0 부터 Lab 8 까지 갑니다.
  프로필을 바꾸는 Lab 은 없습니다.

각 Lab 은 같은 골격입니다.

> **목표** — 이 Lab 이 끝나면 무엇이 참이 되나
> **선행조건** — 없으면 시작하지 말 것
> **소요·비용** — 실측 기준
> **명령** — 복사해서 실행
> **기대 출력** — 실제로 나온 값. 다르면 아래를 본다
> **막히면** — `docs/GOTCHAS.md` 의 해당 항목
> **정리** — 돈이 새지 않게

## 트랙

- **Track A (파인튜닝)**: 0 → 1 → 2 → 3 → **7**
- **Track B (vLLM 배포)**: 0 → 4 → 5 → 6 → **7** — **학습 없이 됩니다** (Lab 5 의 `--hf-model`)
- **풀사이클**: 0 → 1 → 2 → 3 → 4 → 5 → 6 → **8 → 7** — Lab 8 이 Lab 7 보다 **먼저**입니다

**어느 트랙이든 Lab 7 에서 끝납니다.** Track A 는 GPU 클러스터를 껐어도 워크스페이스·
스토리지·KeyVault 가 그대로 남습니다 — 그룹을 지우는 것은 Lab 7 §7 뿐입니다.

> ⚠️ **풀사이클에서 Lab 7 은 번호 순서가 아니라 맨 마지막입니다.**
> Lab 8 은 Lab 5 가 띄운 `blue` 옆에 green 을 올려 트래픽을 넘기는 실습입니다.
> Lab 7 로 먼저 내리면 그 `blue` 가 없어서 24분짜리 배포부터 다시 해야 하고,
> $4.959/시 × 24분 ≈ **$2** 를 산출물 없이 다시 냅니다
> ([lab7.md](lab7.md) 순서표, [lab8.md](lab8.md) 순서).
> **Track B 만 하면** Lab 8 을 건너뛰고 Lab 6 → Lab 7 이 맞습니다.

## 여러분의 숫자가 맞나

각 Lab 의 "기대 출력" 은 [`docs/PERFORMANCE.md`](../PERFORMANCE.md) 의 기준 회차를 잘라 붙인
것입니다. 전체 로드테스트 표(5레벨 × 두 배포)와 `--output` 원자료 JSON 이 거기 있습니다.

## 실습 중 언제든

```bash
uv run ffsft lifecycle status     # 지금 뭐가 돈을 쓰고 있나
```

> **`status` 는 워크스페이스만 봅니다.** `BILLING NOW: nothing` 은 "이 워크스페이스에서
> GPU 가 안 돈다" 이지 "그룹이 비었다" 가 아닙니다. 스토리지·ACR·KeyVault 는 그 뒤에도
> 남아서 과금됩니다 — 그룹 전체를 끝내는 것은 [Lab 7 §7](lab7.md) 의 `ffsft infra down`
> 하나뿐입니다.

## 명령은 `ffsft` 하나입니다

Lab 문서는 전부 `uv run ffsft <cmd>` 형태만 씁니다. `ffsft-lifecycle` 같은 옛 console
script 도 여전히 돌지만, **외울 이름을 하나로 줄인 것**입니다. 지도는 `ffsft --help`
이고 Lab 순서대로 나옵니다 ([Lab 0](lab0.md)).
